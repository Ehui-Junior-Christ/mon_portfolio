    Paramètres du dépôt

    Le dépôt GitHub qui contient le site. Les valeurs par défaut conviennent si vous n'avez rien renommé.

    Aide

    Comment ça marche

    Tout le contenu du site (profil, projets, parcours...) est rangé dans un seul fichier : data/content.json. Cette page le lit sur GitHub, vous le modifiez avec les formulaires, puis « Publier » l'enregistre sur GitHub. GitHub Pages met ensuite environ une minute à mettre le site à jour.

    Créer votre token (une seule fois)

    1. Connectez-vous à GitHub, puis ouvrez directement la page de création de token.
      Chemin manuel : photo de profil → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
    2. Token name : par exemple « Admin portfolio ».
    3. Expiration : choisissez une durée (90 jours par exemple). À l'expiration, il suffit d'en créer un nouveau.
    4. Repository access : Only select repositories, puis sélectionnez mon_portfolio.
    5. Permissions → Repository permissions → Contents : Read and write. Ne touchez à rien d'autre (« Metadata : Read-only » s'ajoute tout seul).
    6. Cliquez sur Generate token, copiez le token (il commence par github_pat_) et collez-le sur l'écran de connexion. GitHub ne l'affiche qu'une fois.

    Sécurité

    • Cette page d'administration est publique (n'importe qui peut l'ouvrir), mais elle est inutilisable sans token. Elle n'est pas indexée par les moteurs de recherche.
    • Ne partagez jamais votre token : c'est une clé qui permet de modifier votre dépôt. Ne l'envoyez à personne, ne le collez nulle part ailleurs.
    • Le token n'est limité qu'au dépôt mon_portfolio et au contenu des fichiers : même perdu, il ne donne pas accès à votre compte.
    • En cas de doute, supprimez-le sur GitHub (Settings → Developer settings → Fine-grained tokens → Revoke) et créez-en un autre.
    • « Se souvenir sur cet appareil » garde le token dans ce navigateur. Sur un appareil partagé, laissez la case décochée et cliquez sur « Se déconnecter » à la fin.

    Astuces

    • Dans les textes : **gras** et *italique*.
    • Vos modifications sont gardées en brouillon dans ce navigateur tant qu'elles ne sont pas publiées.
    • Les images envoyées sont réduites automatiquement (1600 px de large maximum) et rangées dans assets/uploads/. Elles apparaissent sur le site après publication.
    • « Exporter le JSON » télécharge une copie de sauvegarde de tout le contenu. « Importer » la recharge.
    • Si vous voyez une erreur de conflit, c'est que le fichier a été modifié ailleurs (par exemple directement sur GitHub) : rechargez la version en ligne.
