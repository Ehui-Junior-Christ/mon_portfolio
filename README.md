# Ehui Junior Christ — Portfolio

Portfolio personnel d'un développeur web full-stack basé à Abidjan : parcours, projets et quelques mini-jeux.

## Stack

- HTML, CSS, JavaScript (vanilla, sans framework ni étape de build)
- [GSAP](https://gsap.com/) et [Lenis](https://lenis.darkroom.engineering/) pour les animations et le défilement

## Lancer en local

Le contenu est chargé depuis un fichier JSON : servez le dossier avec un petit serveur local (par exemple l'extension **Live Server** de VS Code), plutôt que d'ouvrir `index.html` directement.
